# Actividad 2.2

* **Caso 1:** HTML, CSS y JavaScript básico; al ser una web estática y sencilla, asegura la máxima velocidad y fácil mantenimiento sin herramientas pesadas.
* **Caso 2:** Tecnologías de alto rendimiento para el navegador (como WebAssembly); es ideal para procesar gráficos pesados en tiempo real sin que la interfaz sufra tirones.
* **Caso 3:** TypeScript con un framework estructurado; ofrece la organización estricta y seguridad que un equipo grande necesita para un proyecto financiero a largo plazo.
